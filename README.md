# 🎓 comsci-sskru — เว็บไซต์สาขาวิชาวิทยาการคอมพิวเตอร์ มหาวิทยาลัยราชภัฏศรีสะเกษ

ระบบเว็บไซต์ทางการสำหรับสาขาวิชาวิทยาการคอมพิวเตอร์ คณะศิลปศาสตร์และวิทยาศาสตร์ มหาวิทยาลัยราชภัฏศรีสะเกษ (Computer Science Department Website — SSKRU)

## 🚀 ฟีเจอร์หลัก (Features)
- 📌 **Modern Bento Channel Grid**: รวมช่องทางโซเชียลมีเดียหลัก (LINE AI Chatbot, SSKRU Main Portal, Facebook, TikTok)
- 🎓 **Admissions & Curriculum**: ข้อมูลการรับสมัครนักศึกษาใหม่และโครงสร้างหลักสูตรปรับปรุง พ.ศ. 2568
- 📚 **Study Plan (แผนการเรียน 4 ปี)**: ตารางรายวิชาสำหรับชั้นปีที่ 1 - 4
- 👨‍🏫 **Faculty Profile**: รายชื่อคณาจารย์ประจำหลักสูตรพร้อมวุฒิการศึกษาและปุ่มดูประวัติ
- 🗺️ **Interactive Location Pin**: แผนที่ปักหมุดตำแหน่งมหาวิทยาลัยราชภัฏศรีสะเกษ (SSKRU Location)

## 🛠️ Tech Stack
- **Backend**: Python 3.12, Django 6.1
- **Frontend**: HTML5, Vanilla CSS3, Bootstrap 5.3, FontAwesome 6, Bootstrap Icons
- **Deployment**: Vercel Compatible (`vercel.json`)

## 💻 การติดตั้งและรันในเครื่อง (Local Setup)
```bash
# Clone Repository
git clone https://github.com/poommuse29/comsci-sskru.git
cd comsci-sskru

# สร้าง Virtual Environment
python -m venv venv
venv\Scripts\activate

# ติดตั้ง Dependencies
pip install -r requirements.txt

# รันเซิร์ฟเวอร์
python manage.py runserver
```
